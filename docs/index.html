РЕЖИМЫ

Три сценария работы

OpenCV с маской вокруг текста находит нужные кнопки при разном разрешении экрана.

Метод 1

Повторная игра

Сканирует экран окончания матча и сам нажимает «Играть снова», а при включённом резерве кликает «Играть» в лобби.

Метод 2

Полный цикл через лобби

Запускает матч, ждёт случайный таймер (настройка минут от/до), открывает меню, выходит в лобби и стартует заново.

Метод 3

Только Анти-АФК

Отключает захват экрана и OpenCV, остаётся только движение в Анти-АФК. Удобно для долгих творческих карт и LEGO.

РЕЖИМ «СЛАБЫЙ ИГРОК»

Набор действий для имитации игры

Вместо зажатия одной клавиши по таймеру скрипт перемешивает движения, прыжки и повороты камеры со случайными паузами.

Подкаты и прыжок из подката

Разгон на спринте W + Shift, подкат Ctrl со смещением камеры и выход через Space со стрейфом или полный докат.

Увороты стрейфами A/D

Серии из 3-5 быстрых шагов влево и вправо с небольшим смещением прицела.

Приседания с осмотром

Короткие приседания, двойные пики и присед-стрейфы с точным сохранением баланса тоггла Ctrl.

Удары киркой и прыжок-удар

Одиночные взмахи, серии по 2-3 удара со стрейфом, удержание ЛКМ или прыжок с ударом.

Короткий осмотр ПКМ

Кратковременное прицеливание правой кнопкой с плавным ведением и защитой от срабатывания во время фарма ЛКМ.

Повороты камеры и паузы

Плавные повороты с ограничением угла по вертикали, оглядки назад, микро-дрейф и случайные интервалы между действиями.

БЕЗОПАСНОСТЬ

Без вмешательства в клиент игры

Весь код открыт по лицензии MIT, а готовые .exe собираются в GitHub Actions с проверкой SHA-256.

  • ✓Не читает и не меняет память процесса, не внедряет DLL и не трогает файлы Fortnite.
  • ✓При потере фокуса или сворачивании Fortnite действия сразу ставятся на паузу.
  • ✓Сброс всех клавиш и кнопок мыши (LMB/RMB) при остановке, ошибке или клике меню.
  • ✓Не нажимает Esc, Tab, I, M, B, E во время Анти-АФК, чтобы не открывать лишние меню.
УСТАНОВКА

Два способа запуска

Рекомендуется

Готовый Windows EXE

Автономный исполняемый файл без установки Python и сторонних библиотек.

  1. Скачайте релиз из раздела GitHub Releases по кнопке выше.
  2. Запустите от администратора. Права нужны Windows для отправки скан-кодов поверх окна игры.
  3. Настройте поворот 180° под чувствительность мыши и нажмите F6 в игре (F7 для стопа).
Для разработчиков

Запуск из исходного кода

Требуется Python 3.10+ на Windows 10 или Windows 11.

git clone https://github.com/kiingofhate/pirate-token-farm.git
cd pirate-token-farm

python tests\test_pirate_farm.py
