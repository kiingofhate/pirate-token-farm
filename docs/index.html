ИГРОВОЙ ЦИКЛ

Три сценария фарма под любой режим Fortnite

Масштабируемый OpenCV-поиск с маской фона стабильно находит кнопки при разном разрешении мониторов и оформлении сезонов.

Метод 1

Повторная игра

Сканирует экран окончания матча и сам нажимает «Играть снова», а при включённом резерве кликает «Играть» в лобби.

Метод 2

Полный цикл через лобби

Запускает матч, ждёт случайный таймер (настройка минут от/до), открывает меню, выходит в лобби и стартует заново.

Метод 3

Только Анти-АФК

Полностью отключает захват экрана и OpenCV — работает только генератор движений, идеален для долгих творческих карт и LEGO.

РЕЖИМ «СЛАБЫЙ ИГРОК»

Живое разнообразие действий против АФК-детекции

Вместо однотипного зажатия W и таймера бот смешивает стрейфы, подкаты, увороты и микро-коррекции камеры с аритмичными интервалами.

Подкаты и прыжок из подката

Разгон на спринте W + Shift, подкат Ctrl со смещением камеры и выход через Space со стрейфом или полный докат.

Увороты стрейфами A–D

Серии из 3–5 быстрых смен направления влево и вправо с лёгкой противофазной доводкой прицела.

Приседания с осмотром

Короткие приседания, двойные пики и присед-стрейфы с точным сохранением баланса тоггла Ctrl.

Удары киркой и прыжок-удар

Рандомные взмахи, серии по 2–3 удара с шагом вбок, удержание ЛКМ или комбо прыжок + флик + удар.

Короткий осмотр ПКМ

Кратковременное прицеливание правой кнопкой с плавным ведением и защитой от срабатывания во время фарма ЛКМ.

Живая камера и аритмия

Косинусные повороты с ограничением вертикального угла, оглядки назад, микро-дрейф в паузах и рваный ритм пауз.

ПРОЗРАЧНАЯ АРХИТЕКТУРА

Открытый код и ноль вмешательства в клиент игры

Весь исходный код открыт под лицензией MIT, а готовые .exe собираются публично в GitHub Actions с проверкой хеш-сумм SHA-256.

  • ✓Не читает и не меняет память процесса, не внедряет DLL и не трогает файлы Fortnite.
  • ✓Работает только когда окно игры в фокусе — автопауза при любом Alt+Tab.
  • ✓Сброс всех клавиш и кнопок мыши (LMB/RMB) при остановке, ошибке или клике меню.
  • ✓Не использует клавиши Esc, Tab, I, M, B, E во время Анти-АФК — меню не откроются случайно.
БЫСТРЫЙ СТАРТ

Два способа запуска

Рекомендуется

Готовый Windows EXE

Автономный исполняемый файл без установки Python и сторонних библиотек.

  1. Скачайте релиз из раздела GitHub Releases по кнопке выше.
  2. Запустите от администратора — UAC нужен Windows для отправки скан-кодов поверх окна игры.
  3. Настройте поворот 180° под чувствительность мыши и нажмите F6 в игре (F7 для стопа).
Для разработчиков

Запуск из исходного кода

Требуется Python 3.10+ на Windows 10 или Windows 11.

git clone https://github.com/kiingofhate/pirate-token-farm.git
cd pirate-token-farm
pip install -r requirements.txt
python tests\test_pirate_farm.py
